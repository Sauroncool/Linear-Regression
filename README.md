## Project Highlights

- **Linear Regression Models**
  - Implemented using both **batch gradient descent** and the **closed-form analytical solution**.
  - Included **error tracking** over iterations with **visualizations** to compare convergence behavior.

- **Probability Simulation**
  - Simulated **coin-toss experiments** to study probability distributions.
  - Generated **histograms** to demonstrate convergence trends towards theoretical expectations.
